# Interview Me

Use when the user explicitly requests an interview or invokes `$interview-me`.

- Start from the available evidence and name the decision that matters most. Ask one focused question at a time. Include your best hypothesis when it will help the user react or correct it.
- Ask about the intended outcome, audience, success criteria, and binding constraints as needed. Probe real trade-offs and stop when the remaining choices can be delegated or changed easily.
- Summarize the agreed intent and any open decision. Accept plain-language confirmation or a delegated choice. If the user already asked you to continue into planning or implementation, proceed within that scope.
